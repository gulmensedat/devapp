DevApp
Projeleri, terminalleri ve Claude / Codex'i tek pencereden yöneten macOS uygulaması
Açık kaynak · MIT Ücretsiz macOS 14+ Türkçe / İngilizce

Merhaba arkadaşlar,

Projelerimde Claude Code ve Codex'le çalışırken çok fazla terminal kullanıyordum. Hepsini tek yerden yönetebilmek için kendime bir macOS uygulaması geliştirdim; başkalarının da işine yarayabilir diye açık kaynak olarak paylaşıyorum.

Neler yapıyor?

⚡ Tek tıkla çalıştır
Proje klasörünü eklediğinizde komutları otomatik buluyor: npm / pnpm / yarn script'leri, Makefile, Docker Compose, Flutter, Django, Rails, Cargo, Go, SwiftPM. Projedeki tüm dev server'lar tek tıkla kalkıyor.
🔌 Akıllı portlar
Portları gösteriyor, projeler arası çakışmaları önceden uyarıyor. Port değiştirmek ya da boş port buldurmak tek tık.
🧩 Monorepo uyumlu
apps/, packages/, services/ gibi alt projeler kendi komut ve portlarıyla ayrı gruplanıyor.
🤖 Claude & Codex yan yana
Birden fazla ajanı aynı anda, istenirse her birini ayrı git worktree'de çalıştırabiliyorsunuz. Bir ajan onay beklediğinde oturum turuncuya dönüyor, Dock'ta sayaç çıkıyor.
🖱️ Dock menüsü
Dock simgesine sağ tıklayınca projelere göre tüm açık terminaller, başlat / durdur ve sizi bekleyen oturumlar.
📊 Masaüstü widget'ları
Claude ve Codex'in 5 saatlik ve haftalık kullanım limitleri, çalışan projeler ve açık portlar masaüstünde.

Teknik detaylar

  • Native macOS uygulaması, SwiftUI ile yazıldı (macOS 14 ve üstü)
  • Terminaller gerçek PTY (SwiftTerm): vim, htop, Claude Code ve Codex arayüzleri olduğu gibi çalışıyor
  • Telemetri ya da sunucu yok, her şey kendi Mac'inizde çalışıyor
  • MIT lisanslı ve ücretsiz

Kurulum

Repoyu klonlayıp hemen çalıştırabilirsiniz:

$ git clone https://github.com/gulmensedat/devapp.git
$ cd devapp
$ swift run

Masaüstü widget'lı tam sürüm için README'deki Xcode adımlarını takip edebilirsiniz.
